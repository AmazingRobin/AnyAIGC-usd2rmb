```
在 AnyAIGC（anyaigc.ai）查看模型价格时，价格都是以美元标注的。这个插件在页面上加一个
币种切换开关，点一下就把所有美元价格按你自己设定的汇率换算成人民币显示，不用再心算或者
开计算器。

━━━━━━━━━━━━━━━━━━━━━━
主要功能
━━━━━━━━━━━━━━━━━━━━━━

▸ 一键切换 USD / 人民币
  点击即时切换，无需刷新页面。换算后的价格显示为绿色，一眼就能看出当前不是原始美元价。

▸ 汇率自己填
  默认 1 USD = 6.8 RMB，可以改成你实际的结算汇率（比如银行汇率、信用卡汇率）。
  填完按回车或点「应用」即生效。

▸ 设置自动记住
  你选的币种和填的汇率会自动保存，下次打开页面自动恢复，不用重复设置。

▸ 翻页筛选自动跟进
  切换分页、筛选供应商、展开更多模型时，新出现的价格会自动按当前设置换算。

▸ 两个页面都支持
  · 模型广场（anyaigc.ai/pricing）—— 面板在「倍率」开关左侧，保留 4 位小数
  · 使用日志（anyaigc.ai/console/log）—— 面板在 MPM 标签左侧，保留 6 位小数
    （日志里单次调用花费很小，多给两位小数才看得出差别）

━━━━━━━━━━━━━━━━━━━━━━
隐私说明
━━━━━━━━━━━━━━━━━━━━━━

▸ 不收集任何数据
  插件没有服务器，代码里一行网络请求都没有，也没有任何统计、追踪或广告代码。

▸ 只申请一项权限
  仅申请 storage 权限，用于在你的设备本地记住汇率设置。没有申请 tabs、
  scripting、cookies、history 等任何敏感权限。

▸ 只在一个网站生效
  插件只在 anyaigc.ai 上运行，访问其他任何网站时都不会加载插件代码。

▸ 换算只影响显示
  插件只修改屏幕上显示的文字，不会修改任何提交给服务器的数据，也不会影响你的实际
  账单金额。关掉插件或切回 USD，看到的就是原始数据。

━━━━━━━━━━━━━━━━━━━━━━
使用方法
━━━━━━━━━━━━━━━━━━━━━━

1. 安装插件
2. 打开 anyaigc.ai/pricing
3. 在页面顶部工具栏找到切换面板（在「倍率」开关左边）
4. 把汇率改成你的实际汇率，按回车
5. 点「人民币」，完成

面板会等页面工具栏加载完成后出现，刚打开页面时可能有一两秒延迟，这是正常的。
```

## 单一用途说明

```
本扩展的唯一用途是：在 AnyAIGC 网站（anyaigc.ai）的模型价格页面和使用日志页面，将页面上以美元（USD）标示的价格，按用户自行设定的汇率换算为人民币（CNY）显示，帮助中国用户直观理解 API 调用成本。

扩展在页面工具栏插入一个币种切换面板，用户可点击在「美元」与「人民币」之间切换，并可手动填写自己的汇率。换算完全在用户浏览器本地完成，只改变页面上显示的文字，不修改任何提交给服务器的数据，也不影响用户的实际账单金额。

扩展不含任何其他功能。
```

> 声明了具体域名，商店**依然要求填写此项**。不要跳过。

```
本扩展需要在 https://anyaigc.ai/* 与 https://www.anyaigc.ai/* 上运行内容脚本。

原因：扩展的核心功能是读取页面上已显示的美元价格文本、将其替换为换算后的人民币文本，并在页面工具栏插入币种切换面板。这两项操作都必须在该网站的页面上下文中执行，无法通过其他方式实现。

范围最小化说明：
```

## storage 权限使用理由

```
storage 权限用于在用户本地保存两项界面偏好：

1. anyaigcPricingCurrency —— 当前选择的显示币种，取值仅为 "USD" 或 "RMB"
2. anyaigcPricingRate —— 用户手动填写的美元兑人民币汇率数值，例如 7.15

必要性：若无此权限，用户每次刷新或重新打开页面都需重新选择币种并重填汇率，严重影响可用性。

数据性质：两项均为用户自行设定的界面偏好，不含任何个人身份信息。汇率只是一个用于本地显示换算的数字参数，不涉及账户、卡号、交易记录或余额。

存储范围：使用 chrome.storage.local，数据仅保存在用户本机，不同步、不上传、不离开用户设备，随扩展卸载一并删除。
```
